B738-Auto-HPA

Automatic barometric pressure unit selection for the Boeing 737-800 in X-Plane 11

Overview:
B738-Auto-HPA is a lightweight FlyWithLua script designed for the Boeing 737-800 in X-Plane 11.
The project aims to simplify cockpit operation by automatically selecting the appropriate barometric pressure display unit (hPa).
This is especially useful for flight simulation enthusiasts who regularly operate flights across different regions.

Features:
- Automatic barometric pressure display unit selection.
- Designed for the Boeing 737-800.
- Lightweight Lua script.
- Integration with X-Plane 11 through FlyWithLua.

Requirements:
- X-Plane 11
- FlyWithLua NG
- Boeing 737-800 (Laminar Research)

Installation:
1) Download B738_Auto_HPA_v0.1.lua from this repository.
2) Locate your X-Plane 11 installation directory.
3) Open Resources/plugins/FlyWithLua/Scripts/.
4) Copy the Lua file into the Scripts folder.
5) Start or restart X-Plane 11.
Make sure FlyWithLua is correctly installed and enabled.

Compatibility:
Initial development targets the default Laminar Research Boeing 737-800 in X-Plane 11.
Compatibility with other aircraft and X-Plane versions has not yet been established.
